# 🇮🇳 SchemeSaathi

### Government schemes, made easier.

SchemeSaathi is a prototype intelligent assistant designed to help citizens find potentially relevant government schemes based on their needs and basic personal information.

## 🎯 Problem

Citizens often struggle to find government schemes because information can be spread across different sources and eligibility rules can be difficult to understand.

## 💡 Our Solution

SchemeSaathi follows a simple:

**Ask → Match → Act**

The user describes what they need, and the prototype uses basic rule-based matching to identify potentially relevant scheme categories.

The prototype can consider:

- User requirement
- State
- Age
- Income category

It then provides:

- Likely match status
- Reasons for the match
- Documents that may be required
- Suggested next step

## 🛠️ Technology Used

- Python
- Streamlit
- Rule-based matching
- Structured scheme information

## 🚀 Current MVP

The current prototype demonstrates the core user experience using a simplified dataset and rule-based logic.

It is not an official government eligibility system.

Final eligibility and scheme information should always be verified using current official government sources.
